# excel — модули XLSX спецификаций + окно просмотра

Версия окна: **V2** (04.10.2026 — перевод на каркас `ui_common`)

## Что здесь
| Файл | Что делает |
|---|---|
| `excel_export.py` | **собирает** XLSX-файл спецификации и отчётный XLSX (`create_xlsx`, `create_report_xlsx`) — чистый XML без внешних библиотек (никакого openpyxl) |
| `excel_import.py` | **читает** готовый XLSX спецификации (`read_specification_xlsx`) — возвращает `(разделы, строки)`, строки — словари по столбцам |
| `gui.py` + `excel_gui.bat` | **окно-просмотр**: выбрал файл → видно разделы, строки, колонки (что реально записано) |

Эти модули **автономны**: ни Creo, ни агента им не нужно (только стандартная библиотека Python).
Их использует агент (`spec_tools.py`) для сборки ГОСТ-спецификации из BOM живой сборки Creo.

## Окно (просмотр) — **V2, на каркасе `ui_common` (04.10.2026)**
```
excel_gui.bat
```
- раскладка каркаса: результат **СЛЕВА**, файл **СПРАВА** во вкладке «Файл», строка сводки
  с процентом под таблицей, моноширинный журнал внизу, кнопка **README**;
- поле **«Файл спецификации»** (+ Обзор; после выбора файл сразу читается);
- **путь помнится между запусками**: `agent\data\excel_settings.json` (`last_path`), пишется
  каркасом. Раньше была константа `excel\gui_settings.json`, которую никто не читал и не писал —
  окно каждый раз открывалось с пустым полем;
- чтение XLSX идёт **в потоке каркаса** (`U.run_in_thread`) — раньше разбор выполнялся в главном
  потоке и на большой спецификации окно белело; кнопка «ПОКАЗАТЬ» на время чтения гаснет;
- таблица строится по фактическим колонкам файла (Обозначение, Наименование, Количество, раздел
  и т.д.) — набор колонок перестраивается на дереве каркаса после чтения;
- двойной щелчок по строке — открыть сам XLSX;
- сводка: `строк · с обозначением · %`; в журнале перечислены разделы и колонки;
- собственный метод `show_readme` **удалён** — кнопку даёт каркас (`U.readme_button`).

## Окно НЕ записывает XLSX — и почему
Сборка спецификации требует данных сборки (состав, обозначения, материалы) — их даёт Creo/BOM через агента
(`spec_tools.py`). Выдумывать их в окне нельзя, поэтому здесь только **чтение и показ**.
Запись выполняет агент: `spec_create_active` (живая сборка → XLSX).

## Приёмка
- `excel_import.read_specification_xlsx` проверен на файлах спецификаций дома (возвращает разделы и строки);
- окно показывает те же строки, что читает агент (один и тот же разбор);
- перевод на каркас 04.10.2026: `probe_win_live.py excel` — **OK=7 FAIL=0**;
  `probe_excel_card.py` (смена колонок на дереве каркаса, поток каркаса, настройки) — **OK=7 FAIL=0**;
  `design_check` по окну `excel` — **нет замечаний** (было: каркас; minsize; тяжёлое в потоке).
