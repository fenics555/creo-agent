# ORPHAN SCAN (orphan_scan) — чертежи-сироты (нет модели)

Версия окна: **V2** (04.10.2026 — перевод на каркас `ui_common`)

Класс **Р** (только чтение, Creo не нужен). Ищет чертежи `X.drw[.N]`, у которых **нет своей модели**,
и делит их на три категории:
1. **Не сирота** — `X.prt[.N]` или `X.asm[.N]` лежит в той же папке (точное имя, не префикс).
2. **Модель в другом месте** — рядом нет, но базовое имя есть в инвентаре (`agent.sqlite:models`,
   `harvest.db:models_raw`); Creo найдёт её по `search.pro` — это НЕ сирота.
3. **Сирота** — модели нет ни рядом, ни в инвентаре: PDF для такого чертежа сделать нельзя
   (Creo не открывает чертёж без модели — проверено пробой 23.09.2026).
