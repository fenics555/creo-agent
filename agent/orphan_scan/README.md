# ORPHAN SCAN (orphan_scan)

## ОКНО (для рук)
```
orphan_scan.bat "Z:\PTC\Work\папка"      — отчёт по папке (ничего не меняет)
orphan_scan.bat                          — отчёт по всем путям из Z:\PTC\Work\search.pro
```

## ДВИЖОК (для ИИ и скриптов)
```
python orphan_scan.py [папка...]
```
Логи: `D:\AI\log\orphan_scan\run_<дата>_<время>.txt`
Отчёт: `D:\AI\log\reports\REPORT_spec113_local_leg_<дата>_<время>.md`

## Что делает
Ищет чертежи `X.drw[.N]`, у которых **нет своей модели**, и делит их на три категории:
1. **Не сирота** — `X.prt[.N]` или `X.asm[.N]` лежит в той же папке (точное имя, не префикс).
2. **Модель в другом месте** — рядом нет, но базовое имя есть в инвентаре (`agent.sqlite:models`,
   `harvest.db:models_raw`); Creo найдёт её по `search.pro` — это НЕ сирота.
3. **Сирота** — модели нет ни рядом, ни в инвентаре: PDF для такого чертежа сделать нельзя
   (Creo не открывает чертёж без модели — проверено пробой 23.09.2026).
