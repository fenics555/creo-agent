# КАРТА ПЛАГИНОВ ДОМА (PLUGINS.md)

**Что это.** Один файл на все плагины Creo, которыми дом пользуется или собирается
пользоваться: что подключено в бою, что есть в архиве поставщика, что уже заменено
своим инструментом. Правило: **плагин, который появился в бою, обязан быть здесь же**
— иначе через месяц никто не вспомнит, что он стоит и почему.

**Откуда данные.** Живая часть — из `config.pro` (`protkdat`) и `protk.dat` на диске,
читает `config_audit.py::audit_protk`. Архивная часть — конспекты разбора в
`D:\AI\repo\B&W\`: `02_КАРТА_ПЛАГИНОВ.md` (назначение модулей), `INVENTORY.md`
(73 папки версий, снято чтением имён папок и `license.ini`), `03_МЕХАНИЗМ_УСТАНОВКИ.md`
(установка и регистрация). Чужие формулировки приводятся **цитатой** с номером (RM-…).

**Проверка:** `python dev\vol9_check.py`, в общем прогоне — проверка `plugins_registry`
(`python checks.py`). Плагин в бою, которого нет в разделе «ЖИВАЯ ПРОВЕРКА» ниже, —
это провал проверки `plugins_registry`.

- **SmartHolechart:** правило валидации при обновлении — число колонок совпадает и
  заголовки те же [RM-23710]; `PARAMETER_MUST_EXIST` — требовать существования параметра;
  `MARK_COS` — метка системы координат (иначе `HOLECHART_x`). Живой баг дома: `MARK_COS=YES`

  rename; проверка и обновление relations [RM-14929]; allowed-value list в определении
  параметра [RM-24111] — аналог `make_lst`.
- **SmartOptics 13.0.0.0 меняет имена кнопок** (`ok_pb` → `ok_pushbutton`,
  `cancel_pb` → `cancel_pushbutton`) — **⚠️ mapkey дома могут сломаться**.
- **SmartMenu** — способ добавить свои команды в интерфейс, не правя стандартные mapkey.

## 4. УСТАНОВКА: МЕХАНИЗМ (цитата из архива)

Лицензионный сервер — один на все 15 модулей; `server_install.bat` запускается
**от администратора**, служба `BUW License Server` держит порт 6501. Затем:
1. установить `<ПРОДУКТ> <версия> for Creo Parametric <версия Creo>`;
2. **НЕ настраивать лицензию в конце установки**;
3. скопировать `license.ini` в `<папка установки ПРОДУКТА>\bin`;
4. зарегистрировать в Creo: если `protk.dat` НЕТ в `Common Files\text` — скопировать
   туда `<папка установки ПРОДУКТА>\bin\protk.dat`; если УЖЕ ЕСТЬ — **дописать** его
   содержимое в конец существующего файла.

**Риски перед установкой (перечень из разбора):**
1. запись в боевой `config.pro` и в `Common Files\text` установки Creo — требует бекапа
   и записи в `БЕКАП\ЖУРНАЛ.md`;
2. новая служба Windows `BUW License Server` — порт 6501, автостарт, возможен конфликт
   с доменными политиками;
3. битый `protk.dat` или неподнятый Flex-сервер = отказ инициализации на каждой машине
   флота (5+ машин по `SKILL_creostart_fleet`);
4. смена имён кнопок ломает mapkey (см. SmartOptics выше);
5. совместимость: 12 из 15 модулей не имеют сборки под 13.4;
6. юридический аспект (SolidSQUAD) — решение хозяина.

## 6. ПРАВИЛА ВЕДЕНИЯ КАРТЫ
1. Появился новый `protkdat` в бою → строка `- protkdat <путь>` в раздел 1 **в тот же день**.
2. Раздел 1 читает программа: путь, которого нет в файле, — провал проверки `plugins_registry`.
3. Вендора цитируем дословно с номером (RM-…); если у вендора нет нужного механизма —
   пишем «у вендора нет», а не подбираем аналогию.
4. Версии берутся из `INVENTORY.md` (снимок 03.10.2026), а не на глаз.
