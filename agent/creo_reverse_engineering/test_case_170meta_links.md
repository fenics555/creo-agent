# 🧪 Тестовый сценарий: Проверка цепочек связей (Case Study: 170-meta)

Этот файл предназначен для верификации работы экстрактора `creo_links_new.py`. Мы используем «золотой путь» литейного производства серии **170-meta**, который уже был проанализирован и подтвержден.

## 📌 Контекст сценария
Цепочка описывает путь от **Мастер-модели** через **Отливку** к **Технологическому процессу (CAM)**. Если экстрактор работает правильно, он должен восстановить этот «скелет».

---

## 🔍 Тест-кейсы для проверки

### 1. Проверка классификации (PLM Typing)
**Цель:** Убедиться, что агент правильно определяет роль файла на основе его содержимого.

| Файл (Target) | Ожидаемый PLM-тип | Критерий успеха |
| :--- | :--- | :--- |
| `01d23-170gr1-meta-01-otlivka.prt` | **Деталь-отливка** | Наличие признаков усадки или суффикса `_otl` |
| `01523-170gr1-meta-01.asm` | **CAM-процесс (ASSEM_MFG)** | Обнаружение сигнатуры `ASSEMBLY/ASSEM_MFG` |
| `01e170meta-1-знак2-низ.prt` | **Деталь-заготовка** | Наличие маркера `Base_Part` или суффикса `_z` |

### 2. Проверка иерархии (Inheritance / Master-Link)
**Цель:** Проверить, видит ли экстрактор «генетическую» связь между деталью и её шаблоном.

*   **Источник:** `01e170meta-1-знак2-низ.prt` (Заготовка)
*   **Ожидаемая связь:** `(01e170meta-1-знак2-низ) --[inherit_from_master]--> (170META-1-MASTER)`
*   **Как проверить:** Искать в `LargeText` маркеры `Generic` или `Base_Part`.

### 3. Проверка состава (BOM - Bill of Materials)
**Цель:** Убедиться, что сборки «видят» свои компоненты.

*   **Источник:** `01523-170gr1-meta-01.asm` (Сборка процесса)
*   **Ожидаемая связь:** `(01523-170gr1-meta-01) --[bom_component]--> (Детали/Заготовки)`
*   **Как проверить:** Проверка наличия записей в секции `SolidPersistTable`.

### 4. Проверка технологии (Manufacturing / CAM)
**Цель:** Самый важный тест. Проверить гибридное извлечение (указатели + смыслы).

*   **Источник:** `01523-170gr1-meta-01.asm` (CAM-процесс)
*   **Ожидаемые связи:**
    1.  **Инструмент:** `... --[mfg_tool_for]--> (T0010)`
    2.  **Операция:** `... --[mfg_operation_of]--> (RASTOCHKA, FR50, ...)`
    3.  **Оснастка:** `... --[mfg_fixture_for]--> (10X1-D12)`
*   **Как проверить:**
    *   **Pointer-mode:** Найти `T0010` через `setup_data` $\to$ `id_map_info_ptr`.
    *   **Semantic-mode:** Найти ключевые слова `RASTOCHKA` или `FR50` в пуле `LargeText`.

## 🚩 Чек-лист «Провал / Успех»

| Результат | Признак | Действие |
| :--- | :--- | :--- |
| ❌ **FAIL** | Связи не найдены (0 edges) | Проверить `endianness` и правильность `TOC`. |
| ❌ **FAIL** | Тип файла определен неверно | Проверить сигнатуры `NeuAsmSld`, `FeatDefs`. |
| ❌ **FAIL** | Инструмент найден, но не операция | Проверить паттерны `re.finditer` в `LargeText`. |
| ✅ **SUCCESS** | Все 4 типа связей найдены | **Цель достигнута. Переходить к параметрам.** |
