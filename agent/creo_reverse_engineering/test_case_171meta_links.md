# 🧪 Тестовый сценарий: Проверка цепочек связей (Case Study: 171-meta)

**ВНИМАНИЕ:** Данный файл является **ШАБЛОНОМ (TEMPLATE)** для следующей производственной линии. Конкретные имена файлов и параметры должны быть подставлены после получения бинарных данных по серии **171-meta**.

## 📌 Контекст сценария
Цель — верификация экстрактора на новой серии изделий, аналогичной 170-meta, для подтверждения универсальности "DNA Extraction" метода.

---

## 🔍 Тест-кейсы для проверки (Ожидаемые данные)

### 1. Проверка классификации (PLM Typing)
**Цель:** Убедиться, что агент корректно распознает типы для новой серии.

| Файл (Target) | Ожидаемый PLM-тип | Критерий успеха |
| :--- | :--- | :--- |
| `[171meta-master].prt` | **Мастер-модель** | Наличие признаков MSTR |
| `[171meta-part].prt` | **Деталь (КД)** | Наличие признаков FeatDefs |
| `[171meta-asm].asm` | **Сборка / CAM** | Наличие сигнатуры ASSEMBLY/ASSEM_MFG |

### 2. Проверка иерархии (Inheritance / Master-Link)
**Цель:** Проверить связь между деталями серии 171.

* **Источник:** `[171meta-part-z].prt` (Заготовка)
* **Ожидаемая связь:** `(171meta-part-z) --[inherit_from_master]--> (171meta-master)`
* **Как проверить:** Поиск маркера `Base_Part` в `LargeText`.

### 3. Проверка состава (BOM)
**Цель:** Проверить сборку серии 171.

* **Источник:** `[171meta-assembly].asm`
* **Ожидаемая связь:** `(171meta-assembly) --[bom_component]--> (компоненты 171-й серии)`

### 4. Проверка технологии (Manufacturing / CAM)
**Цель:** Проверить гибридный поиск (указатели + смыслы) для новой серии.

* **Источник:** `[171meta-cam-asm].asm`
* **Ожидаемые связи:**
    1.  **Инструмент:** `... --[mfg_tool_for]--> (Инструмент 171-й серии)`
    2.  **Операция:** `... --[mfg_operation_of]--> (Операции 171-й серии)`

---

## 🚩 Чек-лист «Провал / Успех»

| Результат | Признак | Действие |
| :--- | :--- | :--- |
| ❌ **FAIL** | Связи не найдены | Проверить соответствие паттернов новым именам/маркерам |
| ❌ **FAIL** | Неверный PLM-тип | Обновить `determine_plm_relation_type` |
| ✅ **SUCCESS** | Цепочка 171 восстановлена | **Продолжать масштабирование** |
