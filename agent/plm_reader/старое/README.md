> «Всё остальное — в отдельную папку "старое" **с возможностью удалить!**»

**Эту папку можно удалить в любой момент** — ничего рабочего в ней нет. Проверено фактом
инвентарём (`_inv_dir.py`: разбор импортов по AST, а не поиском строк): ни один файл отсюда
**не импортируется** рабочими модулями и **не входит в поставку** (`version.json`).

## ⚠️ Пробы — не мусор по смыслу

Они вскрывали форматы Creo. **Результаты перенесены в скиллы**
(`repo\Creo\READ\SKILL_creo_read_roles.md`, `repo\Creo\SKILL_GRABLI.md` §83–95), поэтому файлы
больше не нужны. Если продолжать **булевы операции** — писать заново: коды `feat_type`/`op_type`
**не расшифрованы** (открытая задача).
