## 4. 🔥 ГРАБЛИ, СТОИВШИЕ ЧАСОВ (не повторять!)

### 4.1. `"d" * 1 = NaN` → ГРАФ ПУСТ (без единой ошибки в консоли)
```js
const lvl = depth * dir;      // dir = "d" (строка) → NaN → узлы без координат → пустая область
```
**Лечение:** `const sign = (dir === "d") ? 1 : -1; const lvl = depth * sign;`
**Проверка:** в `selfcheck` есть автопроверка — при `* dir` без `const sign` страница не выпускается.

### 4.2. ОДНОИМЁННЫЕ модели в разных папках → 80% связей перепутаны
Проверка `_diag_collide.py`: `KIR-401-60X67-01` — **23 пути**, `1` — **21 путь**,
связей с неоднозначным именем **19 970 из 24 877 (80,3%)**.
**Лечение:** ключ узла = **ПУТЬ**, имя — отдельное поле для показа/поиска.

### 4.3. Скрытое исключение = невидимая катастрофа
```python
except Exception:   # noqa
    pass            # ← функция падала ВСЕГДА, а выводы строились на «данных»
```
Реальная причина: `UnboundLocalError: count_media` (присваивание делает переменную локальной).
**Лечение:** `except` **не глушить** — печатать тип и трассировку, возвращать `None` явно.

### 4.4. TOC-офсет `DwgData` НЕ ведёт к картинке
Строка `DwgData 7e7b2 16b` даёт **363 байта** служебных данных, а JPEG лежит в другом месте.
**Лечение:** искать **по сигнатуре** `FF D8 FF` … `FF D9` + проверка маркера **SOF**
(без SOF попадает мусор 134 КБ–2,5 МБ). Было 6 превью из 300 → стало 224.

### 4.5. BMP в файлах НЕ ВСТРЕЧАЕТСЯ (0 из 300), хотя подсказки №11 и №14 утверждают обратное
**Не строить логику «.drw → BMP».** Собирать **оба** формата, что найдётся (`cut_preview(raw,"all")`).

### 4.6. Гигантская страница = «пустое окно»
**45,9 МБ** — браузер не парсит, выглядит как «граф не работает».
**Лечение:** компактные ключи (числа-индексы) + `graph_page_nodes` (12 000) → **4,0 МБ**.

### 4.7. Стартовый узел без связей = пустой граф
`DISK-PARAMETRIC` имел `состав 0, входит 344` — граф рисовал 1 узел.
**Лечение:** выбирать узел со связями **В ОБЕ СТОРОНЫ** (`o` и `n`) — таких **7 633**.

### 4.8. Шаблоны забивают список
`SBORKA_MM` — входит в **3 682**, `SBORKA_MFG` — 1 975, `MM_PART` — 1 847 (папка `ШАБЛОНЫ`).
**Лечение:** отсев по маске **и** по папке (`ШАБЛОН|НАСТРОЙК|TEMPLATE`).

### 4.9. Правка вставкой по НОМЕРУ СТРОКИ — запрещена (4 аварии за день)
Задвоила JS-функцию (**пустое окно**), CSS-правила (4 копии — «правки не применяются»),
Python-функции (`NameError`), два `return`.
**Лечение:** только замена по **уникальному** якорю; проверить, что якорь даёт **1 вхождение**.

### 4.10. Дубль CSS-правила молча съедает правку
В CSS выигрывает **последнее**. Проверка: `#side{`, `.row img{`, `#main{`, `#card{`, `#graph{` —
каждое **ровно 1 раз** в собранном HTML.

### 4.11. Flex-скролл не работает без `min-height:0`
**Лечение:** `#main{min-height:0;height:100%}` + `#graph{flex:1 1 auto;overflow:auto;min-height:0}`.

### 4.12. Зависание на сети `Z:`

**Лечение:** `graph_scan_budget` (120 с) + `graph_media_limit` (25 000) + кэш.
