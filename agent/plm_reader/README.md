# PLM Reader

Небольшая автономная программа: показывает данные изделий (деталей, сборок, чертежей)
из выбранной папки в виде таблицы — **обозначение, наименование, материал, объём,
происхождение, ревизия, дата, пользователь**.

Работает **локально**, на вашем компьютере. Файлы **не изменяются** — только чтение.
Никакие данные никуда не отправляются. Внешние библиотеки не требуются.

## Что показывает

| Столбец | Что это |
|---|---|
| Обозначение | обозначение изделия (если задано в модели) |
| Наименование | наименование изделия |
| Материал | материал изделия (например, `STEEL_40X`, `12X18H10T`) |
| Объём, мм³ | объём материала изделия, мм³ |
| Роль | для производных изделий: *производная* (заготовка) или *наследование* (отливка, мастер-модель) |
| Родитель | имя модели, от которой изделие произведено (если есть) |
| Ревизия | номер последней ревизии |
| Дата | дата последней записи в истории изделия |
| Пользователь | логин, сохранивший изделие |
| Файл | имя файла |

## Требования

* Windows, Python 3.11 или новее (с модулем `tkinter` — входит в стандартную установку Python).
* Дополнительно устанавливать нечего.

## Запуск

Окном (двойной щелчок по `plm_reader_gui.bat` в этой папке) или из командной строки:

```
python plm_reader.py
```

Без окна (например, для выгрузки в файл) — `plm_reader.bat` или:

```
python plm_reader.py --folder "Z:\PTC\Work" --csv items.csv
```

Параметры командной строки:

| Параметр | Значение |
|---|---|
| `--folder ПАПКА` | папка для обхода (в этом режиме окно не открывается) |
| `--csv ФАЙЛ` | выгрузить таблицу в CSV |
| `--max-mb ЧИСЛО` | пропускать файлы больше указанного размера (по умолчанию 24) |
| `--no-recurse` | не заходить в подпапки |

## Движок (для ИИ и скриптов)

Тот же файл `plm_reader.py` — самодостаточный движок: работает без окна и без агента.
Агент и ночные скрипты зовут его теми же ключами (`--folder`, `--history`), настройки берутся
из `settings.json` рядом, журнал — `D:\AI\log\plm_reader\plm_reader.log`. Одна библиотека
обслуживает все три руки (окно, CLI, движок) — по закону трёх рук.

## Окно

1. **Папка** — путь для обхода. Кнопка **«Выбрать…»** — обзор по диску. Папка **сохраняется**
   и подставляется при следующем запуске.
2. **Пропускать > МБ** — предохранитель: очень большие файлы не читаются.
3. **с подпапками** — обходить вложенные папки.
4. **Сканировать** — начать обход. Строки появляются **сразу по ходу** обхода, окно не «зависает»;
   справа вверху виден текущий файл.
5. **Фильтр** — наберите часть текста (например `asm` или `Корпус`) — таблица покажет только подходящие
   строки. Кнопка **«Сбросить»** возвращает все.
6. **Сортировка** — щёлкните по любому заголовку столбца; повторный щелчок меняет порядок
   (▲ / ▼). По умолчанию сортировка **по столбцу «Файл»**, и «Файл» всегда стоит первым.
7. **Полосы прокрутки** — справа и снизу (для широких таблиц).
8. **Выгрузить в CSV** — сохраняет то, что показано в таблице (с учётом фильтра и сортировки),
   разделитель `;`, кодировка UTF-8 с BOM — открывается в Excel.
9. Двойной клик по строке или **«История выбранного»** — история изменений файла;
   **«История по папке»** — сводная история всех моделей папки.
10. Статус справа показывает прогресс и количество найденных/показанных моделей.

## Столбцы и параметры (кнопка «Столбцы и параметры…»)

* галочками выбирается, **какие столбцы показывать**; «Файл» отключить нельзя (он всегда первый);
* можно задать **имена параметров** для «Обозначение», «Наименование» и «Материал» — через запятую,
  по порядку поиска (подойдут любые имена, в том числе английские). Берётся первый найденный;
* всё это **сохраняется** в `settings.json`, кнопка «Применить и сохранить» — и при следующем запуске
  выбирать уже не нужно.

## История изменений файла

* **В окне:** выделите строку и нажмите **«История выбранного»** (или **двойной клик** по строке) —
  откроется окно со всеми записями: **Ревизия · Дата · Пользователь · Компьютер · Версия Creo · Что изменено**
  (то же, что показывает Creo в «Истории файла», плюс старые записи Pro/ENGINEER — версия вида `4.0`).
* **Столбцы…** — галочками выбирается, какие столбцы показывать (есть и «Путь», и «Тип» модели);
  выбор **сохраняется** в настройках. Сортировка — щелчком по заголовку.
* **Что изменено** — по каждой ревизии: какие **размеры** (`d…`) и **параметры** были переопределены
  при сохранении (из внутренних записей модели). Точные числа «было→стало» по отдельному размеру Creo
  в записи не хранит — значения видно сравнением версий.
* **Версии…** — сравнение версий одного изделия, лежащих рядом в папке (`.prt.1 / .2 / .3 …`):
  было→стало по ревизии/дате, а также объёму и габариту, если они записаны. Выгрузка в CSV.
* **Без окна:**
  ```
  python plm_reader.py --history "путь\модель.prt.1"
  python plm_reader.py --history "Z:\PTC\Work\папка" --history-csv hist.csv
  ```
  `--history` принимает один файл, несколько файлов или целую папку (с подпапками).

## Настройки

Хранятся рядом с программой в файле `settings.json` и заполняются автоматически
(последняя папка, порог размера, обход подпапок, набор столбцов). Можно править вручную:

```json
{
 "folder": "Z:\\PTC\\Work",
 "max_size_mb": 24,
 "recurse": true,
 "columns": ["Обозначение", "Наименование", "Материал", "Объём, мм³",
             "Роль", "Родитель", "Ревизия", "Дата", "Пользователь", "Файл"]
}
```

## Ограничения

* **Пустой объём или пустая история** — не признак ошибки: изделие могло сохраняться без расчёта
  объёма либо является копией, которая ещё не пересчитывалась.
* Инструмент — вспомогательное средство инвентаризации для внутреннего использования;
  он не является официальным продуктом PTC и не заменяет Creo.
* Программа не изменяет, не переименовывает и не перемещает файлы.
