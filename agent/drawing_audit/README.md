# DRAWING_AUDIT — АУДИТ ЧЕРТЕЖА БЕЗ CREO (класс Р)

**Волна 6, этап 4 плана** (`ПЛАН_ОБНОВЛЕНИЯ_10_26\06_ПЛАН_РАБОТ_ПО_ЭТАПАМ.md`).
Проверяет чертёж **по файлу**, ничего в нём не меняя. Саму штриховку и примечания
не рисуем — это дело Creo (прямой запрет плана, раздел «ЧЕГО НЕ ДЕЛАЕМ»).

## ТРИ РУКИ
| Рука | Как запустить | Что делает |
|---|---|---|
| CLI | `drawing_audit\drawing_audit.bat [папка]` | прогон и отчёт, RC 0/1/2 |
| Окно | `drawing_audit\drawing_audit_gui.bat` | дерево замечаний, чек-лист, превью |
| Агент | `drawing_audit` / `drawing_report` | те же проверки из того же движка |

Все три зовут ОДИН движок `drawing_audit.py`, делят лок `D:\AI\log\drawing_audit`
и пишут отчёт в `D:\AI\log\reports\REPORT_drawing_audit_*.md` + CSV.

## ЧТО ПРОВЕРЯЕТСЯ
| Проверка | Что означает | Уровень |
|---|---|---|
| `sheet_size` | формат листа определён (A4…A0) | error |
| `text_readable` | текст извлекается (доля букв ≥ 30 %) | warn |
| `notes_present` | все плашки чек-листа найдены в тексте | warn |
| `graphics` | нет по-настоящему пустых листов (нет ни вектора, ни растра, ни текста) | error |
| `hatch` | графика есть хотя бы на `hatch_pages` листах | warn |
| `empty_page` | страниц без текста и графики нет | warn |

## ЧЕК-ЛИСТ ПРАВИТСЯ ФАЙЛОМ, НЕ КОДОМ
`D:\AI\tools\agent\data\drawing_audit_settings.json`: `notes` (плашки через `;`),
`folders`, `hatch_pages`, `vector_min`, `show_ok`, `preview`. Кнопка «Применить» в окне
записывает файл; при ручном редактировании файл читается при следующем запуске.
