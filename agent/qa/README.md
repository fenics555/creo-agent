# qa — QA тесты

Папка содержит инструменты качественного assurance (тестирование) агентов.

## Содержимое
- `qa_run.py` — основной запуск тестов
- `qa_run_v2.py` — версия 2 запуска тестов
- `mission_test.py` — тест миссии
- `pre_e_qa_run.py.bak` — резервная копия
- `qa_results.json` — результаты тестов
- `run_behavior.py` — тест поведения

## Назначение
Автоматизированное тестирование компонентов агентов.

## Связь с агентом
Отдельное тестовое покрытие, не часть рабочего ядра агента.
