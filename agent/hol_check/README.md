# ТАБЛИЦЫ ОТВЕРСТИЙ (hol_check) — проверка `.hol`

**Класс Р** (руки без Creo и без модели): только чтение файлов, ничего не чинит.

## ЗАЧЕМ ПРОГРАММА
18.09.2026 Creo при каждом старте писал в трейл
`[err_holechart] hole_charts_thread_series — ошибка чтения диаграммы отверстий`.
Причина найдена вживую: в `GOST_DK.hol`, `GOST_GK.hol`, `GOST_MK.hol` шапка `THREAD_DATA`
содержала **разорванное имя колонки** `TAPER_AN` + `GLE WASHOUT_ANGLE`. Файлы починили
24.09.2026 — ошибка ушла (в трейле от 25.09 её уже нет).

Программа ловит такое **до** запуска Creo, чтобы дефект не вернулся тихо.

## ОКНО (рекомендуется)
```
hol_check_gui.bat
```
Каркас `ui_common` (волна 1): результат слева с иконками статуса и **процентом соответствия**,
настройки справа (таблица `Опция | Значение | Статус | Описание`), кнопки
`По умолчанию / Отменить изменения / Применить`, вкладки `Основное / Дополнительно`.
Проверка уходит в поток — окно не замирает.

Настройки окна: `data\hol_check_settings.json` (манифест п.19), поля `folders` и `show_ok`.

## КОНСОЛЬ
```
hol_check.bat                       # боевая папка + СТАРОЕ
hol_check.bat "Z:\...\папка"        # своя папка
```
**Коды возврата:** `0` — ошибок нет · `1` — есть ошибки · `2` — нечего проверять.

## ИЗ АГЕНТА
- `hol_check` — та же проверка из того же движка (блок `hol_tools.py`);
- `hol_report` — последние отчёты.

## ЧТО ПРОВЕРЯЕТСЯ
| Проверка | Уровень |
|---|---|
| файл существует и не пуст | ошибка |
| секция `TABLE_DATA` | ошибка |
| секция `THREAD_DATA` | ошибка |
| в шапке есть `FASTENER_ID` | ошибка |
| **разорванные имена колонок** (главная проверка) | ошибка |
| разделитель: `TAB` норма, `2+ пробела` допустимо | предупреждение |
| колонки шапки совпадают с данными (только для `TAB`) | ошибка / предупреждение |
| неизвестные эталону колонки | предупреждение |
| кодировка (кириллица в `THREAD_NAME`) | ошибка |

## ЖИВЫЕ ФАКТЫ О ФОРМАТЕ (проверено 03.10.2026)
- Файлов `.hol` в боевой папке **18**, в подпапке `СТАРОЕ` ещё **18** — всего 36.
- Разделитель бывает **двух видов**: табуляция (`GOST_DK.hol`) и `2+ пробела` (`ISO.hol`,
  `g6111_konich_60.hol` и др.). Раньше проверка требовала TAB — это было неверно и давало
  72 ложные ошибки; теперь «2+ пробела» — предупреждение, не ошибка.
- Папка `СТАРОЕ` — архив: разрывы там ожидаемы, поэтому ошибки в ней понижаются
  до предупреждений и помечаются «АРХИВ (СТАРОЕ)».

## ГРАНИЦЫ
- **Только чтение.** Ни один файл на `Z:` не изменяется.
- Creo не запускается.
- Эталон имён колонок зашит в `hol_check.py` (`KNOWN_COLS`, 34 имени); новые имена дают
  предупреждение `unknown_cols`, а не ошибку.
