# purge_versions — ЧИСТИЛЬЩИК склада версий Creo (класс Р, автономная программа)

**Что решает.** Creo при каждом сохранении плодит версии: `деталь.prt.1`, `.prt.2`, `.prt.3`…
На складе дома это гигабайты. Программа показывает, что можно убрать, и **переносит** лишнее в бэкап.

⚠️ **Программа ничего не удаляет.** Лишние версии уезжают в папку бэкапа (`shutil.move`) — вернуть можно.
Есть оконный режим и режим консоли. Класс Р: **Creo не нужен, агент не нужен.**

## Два способа запуска

**Окно (рекомендуется):** `purge_gui.bat`
- поля настроек: **Корень**, **Keep**, **Creo-mode**, **Backup Dir**;
- кнопка **ПЛАН** — считает и показывает таблицу «Группа | Версии | Уйдёт» (ничего не двигает);
- кнопка **ЧИСТИТЬ** — включает только после плана, спрашивает подтверждение;
- внизу строка ИНФО: что найдено, сколько освободится, куда уйдёт;
- корни запоминаются в списке (последние 10), настройки — в `gui_settings.json` рядом с программой.

**Консоль:** `purge_versions.bat -r <папка> -k <сколько оставить>` — печатает JSON-план (для скриптов и агента).

## Что считает
- группирует файлы по базовому имени: `.prt/.asm/.drw/.frm/.lay/.sec` **всех версий**;
- оставляет `Keep` последних версий (по номеру), остальные — в бэкап;
- **Creo-mode** — дом-вариант: оставляет **одну** версию и переименовывает её в `<имя>.<расш>.1`
  (так файл лежит на складе дома);
- имена с `-01`, `-v2`, `-v3` на конце считает одиночками и НЕ трогает;
- файлы, которые сейчас открыты (залочены), пропускает с причиной в отчёте.

## Где что лежит
| Что | Где |
|---|---|
| настройки окна | `gui_settings.json` — рядом с программой (переносится вместе с ней) |
| журнал прогонов | `D:\AI\log\purge_versions\purge.log` |
| отчёт последней чистки | `D:\AI\log\purge_versions\last_purge.json` |
| замок (защита от двух чисток сразу) | `D:\AI\log\purge_versions\purge.lock` |
| бэкап по умолчанию | `<корень>\_purge_backup\<ГГГГММДД>\` (или своя папка из поля Backup Dir) |

## Приёмка 23.09.2026 (на пробной папке)
```
было: d1.prt.1…4, s2.asm.1…3, одиночка.prt.1     keep=2
ПЛАН: группы d1.prt [.1,.2,.3,.4], s2.asm [.1,.2,.3], одиночка.prt [.1]
ЧИСТКА: осталось d1.prt.3, d1.prt.4, s2.asm.2, s2.asm.3, одиночка.prt.1
        в бэкап ушли d1.prt.1, d1.prt.2, s2.asm.1
```
Исправлен дефект: раньше в план попадало несуществующее базовое имя (`d1.prt` без версии) → в отчёт
попадала ложная строка «пропущено: файла нет».

## Границы и осторожность
- **Перед чисткой на складе дома** убедитесь, что Creo закрыт: открытый файл программа пропустит,
  но лучше не рисковать;
- `Keep = 1` — это дом-минимум (одна последняя версия); `Creo-mode` дополнительно переименовывает в `.1`;
- «одиночки» (одна версия в папке) не трогаются никогда — чертёж без родителя не пострадает;
- корень `Z:\...` — сетевой: план читается медленно, это нормально.
