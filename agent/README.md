## Как работать с домом
- **Управление:** `python ctl.py up [--browser] [--hidden]` — подъём стека
  (Ollama 11434, CREOSON 8080, copy-server 8000, агент 8765).
  Статус: `python ctl.py status` · сторож: `python ctl.py --watch` ·
  стоп: `python ctl.py down` · рестарт: `python ctl.py restart`.
- **Правки интерфейса:** после изменений в `ui/` прогнать `python dev/ui_check.py`
  и `python dev/ui_probe.py`.
- **Стоп ответа:** пока агент «думает», в окне есть кнопка **■ СТОП** (и клавиша Esc) — она рвёт
  и запрос из окна, и саму генерацию модели (`/ask_cancel`), недоделанный обмен в историю не пишется.
  Проверка: `python dev\stop_button_check.py`.
- **Бекапы:** перед каждой правкой — копия `pre_<метка>_<файл>` в `data\backup\` (ротации нет, папка растёт
  вручную). Автоматические бэкапы боевой базы — отдельно, в `data\backups\`, каждые 6 ч с ротацией по
  настройке `retention` (7 штук по ~215 МБ). Две папки — две разные роли, не смешивать.
- **Секреты:** только `data\secrets.json`, вне git.

## Принципы
- **Руки без ИИ.** Детерминированные операции (скан и индекс, пары PDF/чертёж, чистка версий,
  уборка логов) работают скриптами, планировщиком и кнопками витрины — без обращения к модели.
- **ИИ рядом с руками.** Модель подсказывает инструмент, контролирует результат против плана,
  разбирает неудачи; пишущие операции — только под щитом согласования.
- **Деградация без пустышки.** При недоступной модели прямые вызовы, поиск и панели продолжают работу.
