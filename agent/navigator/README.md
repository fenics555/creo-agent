# navigator — НАВИГАТОР ПО ДОМУ (поиск → деталировка → PDF)

**Что это.** Окно, в котором ты пишешь словами, что ищешь, и сразу получаешь картину изделия:
список сборок/деталей/чертежей → деталировку выбранной сборки → PDF выбранной позиции
с увеличением «рыбий глаз» (кликнул — приблизилось к тому месту, куда кликнул).

**Класс Р:** Creo НЕ нужен, агент НЕ нужен. Работает по **индексу дома** (только чтение):
| База | Таблица | Что берём |
|---|---|---|
| `data\agent.sqlite` | `models` (44 154) | имена, расширения, пути |
| `data\agent.sqlite` | `bom` (36 811) | **деталировка**: `parent → child` + количество |
| `data\harvest.db` | `models_raw` (93 148) | более полный список файлов |
| `data\harvest.db` | `pairs` (24 607) | **PDF к модели/чертежу** + свежесть (`актуален`/`устарел`) |

## Окно
```
navigator_gui.bat
```
1. **Что ищем** — пиши как угодно: `turn`, `турн`, `турновер`, `поворот` (движок сам подбирает варианты
   написания и ищет и по имени, и по **пути** — то есть по папкам изделий). Галочка «только сборки» — оставить лишь сборки.
2. **НАЙДЕНО** — список: тип, имя, папка. Двойной щелчок по строке — открыть папку в проводнике.
   Выбор строки — сразу собирается **ДЕТАЛИРОВКА** справа.
3. **ДЕТАЛИРОВКА** — позиции состава: тип, имя, количество, есть ли PDF, где лежит.
   Кнопка **«Показать полную деталировку (глубже)»** — разворачивает вложенные сборки (до 9 уровней).
4. **PDF** — выбери позицию, и внизу появится её чертёж **маленьким**. Управление:
   * **клик** — увеличить (точка клика остаётся на виду) — «рыбий глаз»;
   * **колесо** — плавный зум;
   * **двойной клик или правая кнопка** — вернуть превью;
   * **Открыть PDF в Acrobat** — полный просмотр;
   * **Сохранить картинку…** — сохранить то, что видно (PNG).

## Консоль (для скриптов)
```
python navigator.py find turn          — список найденного
python navigator.py bom <сборка> [N]   — деталировка до N уровней
python navigator.py pdf <чертёж|модель>— где PDF и рисуется ли страница
```

## Границы (честно)
- **деталировка из индекса**: если модель не проиндексирована, состава не будет — окно об этом скажет.
  Живую деталировку из Creo (CREOSON/`bom get_paths`) можно добавить отдельной кнопкой позже;
- **деталировка читает чужую таблицу `bom` только на чтение** (закон дома) — ничего не пишет;
- PDF показывается **первой страницей**; листать страницы в окне пока нельзя (для этого — «Открыть в Acrobat»);
- поиск по словам без индекса «по смыслу»: ищем по подстроке в имени и пути (нечёткий поиск по словам — тема развития).
