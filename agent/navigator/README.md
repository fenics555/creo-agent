# navigator — НАВИГАТОР ПО ДОМУ (поиск → деталировка → PDF)

Версия окна: **V2** (04.10.2026 — перевод на каркас `ui_common`: `make_root` даёт заголовок
с версией и minsize, моноширинный журнал и кнопку README даёт каркас; собственная раскладка
поиска/деталировки/PDF с рыбьим глазом сохранена как есть).

**Что это.** Окно, в котором ты пишешь словами, что ищешь, и сразу получаешь картину изделия:
список сборок/деталей/чертежей → деталировку выбранной сборки → PDF выбранной позиции
с увеличением «рыбий глаз» (кликнул — приблизилось к тому месту, куда кликнул).

**Класс Р:** Creo НЕ нужен, агент НЕ нужен. Работает по **индексу дома** (только чтение):
| База | Таблица | Что берём |
|---|---|---|
| `data\agent.sqlite` | `models` (44 154) | имена, расширения, пути |
| `data\agent.sqlite` | `bom` (36 811) | **деталировка**: `parent → child` + количество |
| `data\harvest.db` | `models_raw` (93 148) | более полный список файлов |
| `data\harvest.db` | `pairs` (24 607) | **PDF к модели/чертежу** + свежесть (`актуален`/`устарел`) |

## Окно
```
navigator_gui.bat
```
1. **Что ищем** — пиши как угодно: `turn`, `турн`, `турновер`, `поворот`, можно **словами**: `turn блок`
   (движок сам подбирает варианты написания, ищет и по имени, и по **пути** — то есть по папкам изделий,
   и ставит выше те строки, где совпало больше слов). Галочка «только сборки» — оставить лишь сборки.
2. **НАЙДЕНО** — список: тип, имя (со счётом слов), папка. Двойной щелчок — открыть папку в проводнике.
   Выбор строки — сразу собирается **ДЕТАЛИРОВКА** справа (из индекса дома).
3. **ДЕТАЛИРОВКА** — позиции состава: тип, имя, количество, есть ли PDF, где лежит.
   Кнопка **«Показать полную деталировку (глубже)»** — разворачивает вложенные сборки (до 9 уровней).
   Кнопка **«Состав из живой сессии (Creo)»** — берёт состав **из запущенного Creo** (CREOSON):
   окно само откроет модель без показа, прочитает состав и **уберёт её из сессии**.
   Живые факты 23.09.2026: CREOSON требует имя **без версии** (`d25.asm`, не `d25.asm.1` — иначе
   «Unknown Model Extension») и модель должна быть **открыта** (иначе «File … was not open»).
4. **PDF** — выбери позицию, и внизу появится её чертёж **маленьким**. Управление:
   * **клик** — увеличить (точка клика остаётся на виду) — «рыбий глаз»;
   * **колесо** — плавный зум;
   * **двойной клик или правая кнопка** — вернуть превью;
   * **Открыть PDF в Acrobat** — полный просмотр;
   * **Сохранить картинку…** — сохранить то, что видно (PNG).

## Куда пишет и откуда читает (сверено с живыми вызовами 03.10.2026)
| Роль | Путь | Режим |
|---|---|---|
| ЧТЕНИЕ: имена и состав | `data\agent.sqlite` → `models`, `bom` | только чтение |
| ЧТЕНИЕ: полный список файлов, PDF-пары | `data\harvest.db` → `models_raw`, `pairs` | только чтение |
| ЧТЕНИЕ: живая сессия (кнопка состава) | `creo_tools` агента → CREOSON → запущенный Creo | чтение + открытие/закрытие модели |
| ЗАПИСЬ: настройки | `agent\data\navigator_settings.json` | запись |
| ЗАПИСЬ: журнал | `D:\AI\log\navigator\run_<дата>.txt` | запись |
| ЗАПИСЬ: PNG по кнопке | куда укажет человек (диалог) | запись по запросу |

Чужие базы не изменяются: соединение открывается как `file:…?mode=ro`.

## Настройки — одно место
`D:\AI\tools\agent\data\navigator_settings.json` (создаётся сам, при отсутствии берутся умолчания):
```json
{"agent_db": "...\\agent.sqlite", "harvest_db": "...\\harvest.db",
 "preview_w": 300, "max_zoom": 8.0, "last_query": "turn"}
```
`preview_w` — ширина маленького превью, `max_zoom` — предел увеличения, `last_query` —
запрос, на котором окно откроется в следующий раз. Раньше всё это было зашито в код.

## Консоль (для скриптов)
```
python navigator.py find <слова>     — список найденного
python navigator.py bom <сборка> [N]  — деталировка до N уровней
python navigator.py pdf <чертёж>      — где PDF и рисуется ли страница
```
Коды возврата: **0** — нашли · **1** — пусто (состава/совпадений нет) · **2** — неверный вызов.

## Границы (честно)
- **деталировка из индекса**: если модель не проиндексирована, состава не будет — окно об этом скажет.
- **деталировка читает чужую таблицу `bom` только на чтение** (закон дома) — ничего не пишет;
- кнопка состава из живой сессии **трогает сессию**: открывает модель без показа и убирает её
  (`file open display=False` → `bom get_paths` → `file erase`). Живой факт: CREOSON требует имя
  **без версии** (`d25.asm`, иначе «Unknown Model Extension») и модель должна быть открыта;
- PDF показывается **первой страницей**; листать страницы в окне пока нельзя (для этого — «Открыть в Acrobat»);
- поиск по словам без индекса «по смыслу»: ищем по подстроке в имени и пути.
