# cmnm_scan V2 — внутренние имена Creo-файлов (класс Р, без Creo)

## Зачем
Внутри Creo-файла есть заголовок с внутренним именем модели (поле `#- CMNM`). Если оно **расходится**
с именем файла, Creo **не открывает** модель по имени файла (`XToolkitNotFound`). Такие файлы выглядят
целыми, но в сборке «не находятся». Проверять это надо заранее — до открытия в Creo.

## ОКНО С НАСТРОЙКАМИ (рекомендуется)
```
cmnm_scan_gui.bat
```
- **Где проверять** — список папок (Добавить / Убрать);
- **лимит файлов** (0 — без предела);
- **ПРОВЕРИТЬ** (обход в отдельном потоке, внизу пишется ход);
- таблица: Файл · «Внутри файла» · Папка (двойной щелчок по строке — открыть папку файла);
- **Сохранить список (CSV)** — расхождения в файл (для передачи в работу);
- настройки окна — `gui_settings.json` рядом с программой.

## КОНСОЛЬ
```
cmnm_scan.bat <папка> [ещё папки] [--limit N]
```
или `python cmnm_scan.py <папка>` (в бате добавлен `-X utf8` — в отчёте есть стрелка «→»).

## ЖИВАЯ НАХОДКА 02.10.2026 (аудит): длина в префиксе — в БАЙТАХ, и точка не нужна

Прежнее правило среза префикса (`23.09.2026`) было: `abs(len(остаток) - префикс) <= 1` **и точка в имени**.
Оно давало **ложную тревогу на 27% файлов** — 131 из 490 на папке `Z:\PTC\Work\000_57 СЕРЬГИ, ТЯГИ`:

```
al-1110-06_000.asm.1   → внутри «01aал-1110-06_000.asm»   # ложное: префикс 0x1a = 26 БАЙТ, а символов 24
чсз-л_301_008_03.drw.1 → внутри «018чсз-л_301_008_03.drw» # ложное: то же, кириллица по 2 байта
04501762.drw.1         → внутри «00804501762»             # ложное: длины сходятся (8), но нет точки
```

Правило теперь: длина сверяется **в байтах UTF-8**, точка не требуется.
Проверка на тех же 490 файлах: **131 ложное → 0**; осталось 86 расхождений и они **настоящие**
(файл назван по коду `04501482-01-z`, внутри имя `04501482-z` — Creo такой файл по имени не откроет).

## ЖИВАЯ НАХОДКА 02.10.2026 (аудит): окно — три отладки

1. **Список папок портился в настройках.** `tk.StringVar.get()` у списка отдаёт строку
   `«('D:\\AAA', 'D:\\BBB')»`, а код делал `list(...)` → в `gui_settings.json` попадал
   **список букв** (`["(", "'", "D", ":", ...]`). Теперь список — `tk.Variable`,
   чтение идёт из самого списка (`lst.get(0, "end")`), а битый список при загрузке выкидывается.
2. **Падение в фоновом потоке.** `int(self.var_limit.get())` вызывалось в рабочем потоке →
   `RuntimeError: main thread is not in main loop`. Теперь все значения окна читаются в главном потоке.
3. **Окно не оставляло следа:** отчёты писала только консоль, а кнопка «Открыть папку отчётов»
   показывала папку с чужими файлами. Теперь окно пишет отчёт в тот же формат и ту же папку.

## Что делает
1. обходит папки (по подпапкам), берёт `.prt`, `.asm`, `.drw`, `.frm`, `.sec`, `.lay` (все версии `.N`);
2. читает заголовок файла и достаёт внутреннее имя модели;
3. **отрезает 3-значный HEX-префикс длины** (сверка длины — в байтах UTF-8, см. находку выше);
4. печатает расхождения и итог, пишет отчёт `D:\AI\log\cmnm_scan\run_<дата>_<время>.txt`;
   хранятся последние **20** отчётов (`CMNM_REPORT_KEEP`), папка убирается `log_clean` (56 дней);
5. если папки из списка нет на диске — пишет `ВНИМАНИЕ`, а не молча «0 файлов».

## ЖИВАЯ НАХОДКА 23.09.2026 (была ложная тревога на 100% файлов)
В заголовке внутреннее имя идёт **с префиксом длины**:
```
#- CMNM 007d25.asm        → внутреннее имя «d25.asm»  (007 = 7 символов)
#- CMNM 00bplatina.prt    → «platina.prt»             (00b = 11)
```
Прежний разбор считал префикс частью имени и показывал расхождение **на каждом файле**
(на пробной папке: 7 из 7 «расхождений» при полностью здоровых моделях).
Исправлено: `strip_len_prefix()` отрезает префикс, если он согласован по длине и остаток похож на имя файла.
Проверено на тех же 7 файлах: **было 7 расхождений → стало 0**.

## Что делать с настоящим расхождением
- если внутри чужое имя — модель надо **пересохранить** (Creo → «Сохранить как» с правильным именем) или
  переименовать файл под внутреннее имя;
- НЕ переименовывайте файл «на глаз»: у сборок, где он используется, ссылка идёт по **внутреннему** имени.

## Границы
- это **отчёт**, программа ничего не меняет и не удаляет;
- `--limit N` — сколько файлов просмотреть (страховка для больших папок);
- заголовок читается у файлов Creo (не у PDF/текста).

## Связанное
- `dup_scan` (двойники) и `orphan_scan` (чертежи-сироты) — соседние проверки того же класса;
- причина расхождения обычно одна: файл переименовали в Проводнике.
