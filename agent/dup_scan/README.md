# ДВОЙНИКИ (dup_scan) — отдельная программа класса Р

**Класс Р** (руки без Creo и без модели): ищет одинаковые файлы по содержимому (sha1) и говорит,
где лишние копии. Агент и Creo не нужны — программа самодостаточна.

## ОКНО С НАСТРОЙКАМИ (рекомендуется)
```
dup_scan_gui.bat
```
- **Где искать** — список папок (Добавить / Убрать; двойной щелчок — открыть папку в проводнике);
- **Расширения** (`prt,asm,drw,pdf`) и **«не меньше, МБ»**;
- переключатель **«только отчёт» / «переносить в _trash_dup»**;
- кнопка **НАЙТИ ДВОЙНИКОВ** (ищет в отдельном потоке, внизу пишет ход), таблица: МБ · Образец · Двойников · Где лежат;
- кнопка **ПЕРЕНЕСТИ В УРНУ** — активна только в режиме переноса и после поиска, спрашивает подтверждение;
- настройки окна хранятся в `gui_settings.json` рядом с программой (переносятся вместе с ней).

## КОНСОЛЬ (для скриптов и ИИ)
```
dup_scan.bat "Z:\PTC\Work\000_12 MPG ..." --min-mb 0.2 --ext prt,asm,drw      — отчёт (ничего не меняет)
dup_scan.bat "Z:\PTC\Work\000_12 MPG ..." --min-mb 0.2 --ext prt,asm,drw --apply   — перенести двойников в _trash_dup
```

## ДВИЖОК (для ИИ и скриптов)
```
python dup_scan.py <папка> [ещё папки] [--min-mb N] [--ext prt,asm,drw,pdf] [--apply]
```
* без `--apply` — **только отчёт**, ничего не меняется;
* с `--apply` — лишние копии **переносятся** в `_trash_dup` рядом с образцом (никогда не удаляются);
* образец — самый свежий файл группы (по mtime);
* Creo-версии понимаются: `x.prt.1` — это расширение `prt`, а не `1`;
* отчёт: консоль + `D:\AI\log\dup_scan\run_<дата>_<время>.txt`.

## Что ищет и чего не делает
* ищет **точные** двойники (одинаковое содержимое, имя и папка могут отличаться);
* НЕ ищет «похожие» файлы (по геометрии/имени) — это другая задача, требует Creo;
* служебные папки `_trash`, `_trash_dup`, `.git`, `backup`, `node_modules` пропускает.
