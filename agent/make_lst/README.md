# make_lst — файл ограничений параметров дома (`list.lst`)

Версия окна: **V2** (04.10.2026 — перевод на каркас `ui_common`)

## Зачем
Чтобы в Creo параметры дома (`ТИП`, `ТИП2`, `ФОРМАТ`, `РОЛЬ_В_ЛИТЕЙНОЙ_СИСТЕМЕ`) выбирались **из списка**,
а не писались руками. За это отвечает опция `config.pro`:
```
restricted_val_definition Z:\PTC\CREO-START\НАСТРОЙКИ\ФАЙЛЫ_ОГРАНИЧЕНИЙ_ПАРАМЕТРОВ\list.lst
```
Этот файл и собирает программа. Класс Р: чистый Python, **Creo не нужен**, агент не нужен.

## КОНСОЛЬ
```
make_lst.bat                  # записать боевой list.lst (прежний уедет в _pre\ с меткой времени)
make_lst.bat --dry            # только показать, ничего не писать
make_lst.bat --from refs.txt  # сверить с отчётом чесалки (creo_comb refs) и записать
make_lst.bat --target <путь>  # другой файл (для пробы)
```
Коды возврата: **0** — записано/показано · **2** — неверный ключ или не записалось.
Журнал прогона: `D:\AI\log\make_lst\run_<дата>_<время>.txt` — пишут **и консоль, и окно**
(метка с секундами: два прогона в одну минуту не затирают журнал).

## Куда пишет и откуда читает (сверено с живыми вызовами 03.10.2026)
| Роль | Путь | Режим |
|---|---|---|
| ЗАПИСЬ: боевой файл | `Z:\PTC\CREO-START\НАСТРОЙКИ\ФАЙЛЫ_ОГРАНИЧЕНИЙ_ПАРАМЕТРОВ\list.lst` (cp1251) | по кнопке ЗАПИСАТЬ / без `--dry` |
| ЗАПИСЬ: бэкапы прежнего | `_pre\` рядом с целью, имя `<дата>_<время>[_N]_list.lst` | авто перед записью; хранится **20** последних |
| ЗАПИСЬ: журнал | `D:\AI\log\make_lst\run_*.txt` | каждый прогон, консоль и окно |
| ЧТЕНИЕ | `refs.txt` (отчёт чесалки), сам `list.lst` («Показать текущий файл») | только чтение |
| СОЗДАЁТ папку | папку цели, если её нет (`os.makedirs`) | — |
Ничего больше не создаётся и не удаляется. Путь цели задан в `config.pro`:
`restricted_val_definition …\list.lst` — это источник истины, программа пишет ровно туда.

## Формат файла (строгий, иначе Creo ругается)
- кодировка **cp1251**, переводы строк **CRLF**;
- между записями — **три** пустые строки; последняя запись — **без** запятой;
- закрывающая `}` и четыре пустые строки в конце.
Признак ошибки формата в Creo: `syntax error ... unexpected token: }`.

## Что уже проверено живьём (23.09.2026)
- Creo файл принимает, ограничения в диалоге «Параметры» работают;
- **пустой вариант** дома пишется как `' '` (пробел). Creo **не даёт** через API создать ограниченный
  параметр со значением-пробелом (`XToolkitNotValid`) — поэтому чесалка при `add` такие параметры
  пропускает и докладывает (или берёт первое значение при `--empty-first`).

## Что исправлено в аудите 03.10.2026
1. **Бэкап прежнего файла затирался.** Метка времени была с точностью до **минуты**, поэтому два
   прогона в одну минуту писали бэкап в одно имя. Живая проба: положил файл 48 байт, дважды запустил
   запись в одну минуту — в `_pre` остался **один** бэкап на 697 байт, оригинала нет.
   Теперь метка с **секундами** + номер, старый бэкап не трогается.
2. **Бэкапы копились вечно.** Добавлена ротация: хранятся **20** последних, удаляются только файлы
   с нашей меткой имени (проверено: чужой `DLYA_DISKOV.lst` в той же папке не тронут).
3. **Окно не писало журнал вообще.** Канон показывал `Log: True` (искал слово «log» в коде),
   а след на диске оставляла только консоль. Теперь окно и консоль пишут **один и тот же** журнал.
4. **Бат терял код возврата и кодировку.** `python …` без `exit /b %ERRORLEVEL%` → `make_lst.bat
   --nosuchkey` отдавал **0** вместо 2; не было `-X utf8` → русский шёл кракозябрами. Исправлено,
   проверено: `--nosuchkey` → **2**, `--dry` → **0**.
5. **Журнал назывался с точностью до минуты** — два прогона затирали друг друга. Теперь с секундами.
6. Незаписываемый путь больше не роняет программу: цель проверяется на диске после записи, при
   неудаче — `RC=2` и запись в журнал «НЕ ЗАПИСАН».

## Границы
- программа пишет **только** `list.lst`, свои бэкапы и свой лог; из чужого не удаляет ничего;
