# Варианты окна агента (для выбора «как должно выглядеть»)

Три раскладки **одного и того же** окна. Данные во всех — **живые**: `live.js` тянет
`/api/programs` (программы дома из `data\programs.json`), `/api/bases` (базы с размерами),
`/api/jobs` (общий журнал работ), а кнопки зовут `/prog_run` и `/prog_state`.

## Как посмотреть
1. Подними стек: `python ctl.py up` (агент 8765).
2. Открой в браузере **тот же** адрес, где ты работаешь с агентом (`http://127.0.0.1:8765`) и войди —
   нужно, чтобы в браузере был токен входа.
3. Затем открой варианты (агент отдаёт их сам, папка `ui\variants\`):
   - `http://127.0.0.1:8765/ui/variants/v1_tabs.html` — **вкладки сверху**
   - `http://127.0.0.1:8765/ui/variants/v2_side.html` — **боковое меню** (рейл как в VS Code/Creo)
   - `http://127.0.0.1:8765/ui/variants/v3_pult.html` — **пульт с плитками** (всё видно сразу)

Переключаться между вариантами можно сверху страницы, не закрывая окно.

## Чем отличаются

| Вариант | Раскладка | Сильная сторона | Слабая сторона |
|---|---|---|---|
| **1 · вкладки сверху** | вкладки Чат / Программы / Базы / Настройки / Команда + диалог в центре | привычно, диалог широкий, меньше всего перестроек от текущего окна | «Программы» и «Базы» по очереди — не видно одновременно |
| **2 · боковое меню** | рейл слева, широкая рабочая зона, панель состояния справа | широкая зона под таблицы (программы списком, спецификации, логи) | узкий диалог; на маленьком экране тесно |
| **3 · пульт** | четыре зоны сразу: программы, базы, ход работ, диалог | всё перед глазами: видно, что работает прямо сейчас | плотно; на 1366×768 часть панелей мелкая |

## Что здесь настоящее, а что макет
- **Настоящее:** список программ (из `programs.json`), размеры и свежесть баз, ход работ, состояние
  «кто вошёл / Ollama / CREOSON», кнопки «Запустить» (для программ с разрешённым движком), «Журнал».
- **Макет:** диалог (поле ввода и сообщения), группы инструментов справа, «Настройки» и «Команда».
  При выборе варианта диалог и инструменты вставляются из текущего окна без переделки логики.

## Порядок действий
1. Ты выбираешь вариант (можно «гибрид»: например, вкладки сверху + ход работ всегда внизу).
2. Я переношу выбранную раскладку в **боевое** `ui\index.html` + `ui\app.js` (с бэкапом), диалог и
   инструменты подключаю как есть; лишние варианты удаляю из папки.
3. Проверка: `python dev\ui_check.py` + обход витрины (`ui_probe.py`).
