# ui — веб-интерфейс агента

Папка содержит файлы веб-интерфейса агента (стиль VS Code).

## Содержимое
- `index.html` — основная страница интерфейса
- `app.js` — клиентская логика
- `graph.html` — страница графа
- `map.html` — страница карты

## Назначение
Веб-интерфейс для мониторинга и управления агентом через браузер.

## Связь с агентом
Часть ядра агента — используется для доступа к функциям агента через HTTP.
