# config_audit — проверка путей config.pro (класс Р, без Creo)

## Зачем
Конфиг дома — 381 строка и полсотни путей. Если файл/каталог пропал (переименовали, не завезли на новую
машину), Creo не скажет об этом прямо: он просто молча работает без настройки. Программа проверяет
**каждый путь** и говорит, чего нет. Родилась на аудите дома 23.09.2026: нашлись опечатка `.prt1`
и мёртвый `$PROSTD\weld`.

## Запуск
```
config_audit.bat                    # боевой config.pro (Z:\PTC\CREO-START\START-STD\config.pro)
config_audit.bat <путь\config.pro>  # любой другой (например, локальный кэш CREO-LOCAL-START)
```
Ничего не меняет: только чтение и отчёт в консоль.

## Что умеет
- берёт из строки **значение** (отрезает хвостовой комментарий `! …`), понимает `\` и `/`;
- подставляет переменные Creo: `$PRO_DIRECTORY`, `$CREO_COMMON_FILES`, `$PROSTD`;
- учитывает **версии Creo**: `mm_part.prt` → на диске `mm_part.prt.1` — это «есть»;
- печатает: `путей проверено / НЕТ на диске` и по каждому проблемному — строку конфига и путь на диске.

## Пример (23.09.2026)
```
путей проверено: 56 | НЕТ на диске: 2
строка 119: ncmdl_billet_stock_part_path     ← было .prt1 (опечатка) → исправлено на .prt
строка 164: pro_weld_params_dir              ← $PROSTD\weld, каталога нет → отключено
```

## Границы
- проверяет **файлы**, а не смысл настройки: «файл есть» ≠ «настройка верна»;
- пути внутри файлов (например, содержимое `search.pro`) не проверяются — это работа `orphan_scan`;
- если путь содержит пробелы — берётся вся строка целиком (проверено на
  `protkdat D:\CGTech\VERICUT 9.0.1\...\protk.dat`).
