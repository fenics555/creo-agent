# copy_server — служба копирования и переименования (для веб-страниц дома)

## Зачем
Веб-страницы дома (`copy_web\copy.html`, `creojs.js`) не умеют сами копировать файлы на диске —
браузеру это запрещено. Эта небольшая служба даёт им API на своём компьютере:
подготовить папку под копии, скопировать выбранные файлы, почистить временную папку,
прочитать/дописать журнал переименований и граф.

## ОКНО (управление службой)
```
copy_gui.bat
```
- поля **Порт** (по умолчанию 8000) и **Адрес привязки** (`127.0.0.1` — только своя машина;
  `0.0.0.0` — вся сеть, осторожно);
- кнопка **ЗАПУСТИТЬ СЛУЖБУ** — поднимает движок и показывает его вывод; **ОСТАНОВИТЬ** — снимает процесс;
- **Открыть страницу** — браузер на `http://127.0.0.1:<порт>/copy.html`;
- **Проверить порт** — занят/свободен (если порт занят, значит службу уже поднял стек агента — `ctl.py up`);
- настройки окна — `gui_settings.json` рядом с программой.

## КОНСОЛЬ / СТЕК
```
python copy_server.py [--port 8000] [--bind 127.0.0.1] [--quiet]
```
Стек агента (`python ctl.py up`) поднимает эту службу сам на порту 8000 — отдельного автозапуска не нужно.

## API (то, чем пользуются страницы)
| Метод | Точка | Что делает |
|---|---|---|
| GET | `/`, `/copy.html`, статика | отдаёт страницу и её файлы из `copy_web\` |
| POST | `/api/assembly-copy-workspace-frame` | `{"action":"prepare"}` — временная папка + план переименования (`файл` → `файл_copy`); `{"action":"collect"}` — копирование выбранных (вернёт `copied/occupied/missing`); `{"action":"cleanup"}` — убрать временную папку |
| POST | `/api/rename-copies-frame` | чтение/допись журнала `rename_copies.json` в рабочей папке |
| POST | `/api/save-rename-graph-frame` | записать граф переименований `rename_graph.json` |
| POST | `/api/load-rename-graph-frame` | прочитать граф |

## Границы
- служба **не удаляет рабочие файлы**: только копирование и журналы; временные папки (`creo_copy_…`) удаляются
  своей же командой `cleanup`;
- по умолчанию слушает только `127.0.0.1` — снаружи недоступна;
- если порт занят, окно это покажет и предложит просто открыть страницу уже работающей службы.

## ПЕРЕНОС НА ДРУГУЮ МАШИНУ
Копировать папку `copy\` целиком (`copy_server.py`, `copy_web\`, `gui.py`, бат, настройки, README).
Нужен только Python.
