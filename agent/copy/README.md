# copy_server — служба копирования и переименования (для веб-страниц дома)

## Зачем
Веб-страница дома (`copy_web\copy.html`) не умеет сама копировать файлы на диске — браузеру это
запрещено. Эта небольшая служба даёт ей API на своём компьютере: подготовить папку под копии,
скопировать выбранные файлы, почистить временную папку, прочитать/дописать журнал переименований
и граф.

## СОСТАВ ПАПКИ (сверен с диском 02.10.2026)
| Файл | Что это |
|---|---|
| `copy_server.py` | **движок**: HTTP-служба + API + журнал |
| `gui.py` | окно управления (порт, привязка, старт/стоп, страница, лог) |
| `copy_gui.bat` | **рука 2** — запуск окна |
| `copy_web\copy.html`, `copy_web\copy.css` | страница и её стиль |
| `README.md` | этот паспорт |

Руки программы: **служба** (`python copy_server.py`) и **окно** (`copy_gui.bat`); обе зовут один
движок. Визарда витрины нет — долг.

## ЧТО ОТКУДА ЧИТАЕТ И КУДА ПИШЕТ
| Роль | Путь | Режим |
|---|---|---|
| ЗАПИСЬ: копии | путь, указанный на странице (`target`) | по команде |
| ЗАПИСЬ: временные папки | `%TEMP%\creo_copy_*`, внутри лежит метка `.copy_server_tmp` | создание и уборка |
| ЗАПИСЬ: журнал | `D:\AI\log\copy\run_<дата>.txt` | запись |
| ЗАПИСЬ: настройки окна | `agent\data\copy_settings.json` | запись |
| ЗАПИСЬ: журналы страниц | `rename_copies.json`, `rename_graph.json` в рабочей папке | по API |
| ЧТЕНИЕ | сетевой диск с моделями, файлы `copy_web\` | только чтение |

Служба **не удаляет чужие папки**: `cleanup` сносит только помеченную (`creo_copy_*` + метка внутри).

## ОКНО (управление службой)
```
copy_gui.bat
```
- поля **Порт** (по умолчанию 8000) и **Адрес привязки** (`127.0.0.1` — только своя машина;
  `0.0.0.0` — вся сеть, осторожно);
- кнопка **ЗАПУСТИТЬ СЛУЖБУ** — поднимает движок и показывает его вывод; **ОСТАНОВИТЬ** — снимает процесс;
- **Открыть страницу** — браузер на `http://127.0.0.1:<порт>/copy.html`;
- **Проверить порт** — занят/свободен (если порт занят, значит службу уже поднял стек агента — `ctl.py up`);
- настройки окна — `agent\data\copy_settings.json` (в папке программы файла настроек нет — раньше
  окно писало именно туда и молча теряло всё).

## КОНСОЛЬ / СТЕК
```
python -X utf8 copy_server.py [--port 8000] [--bind 127.0.0.1] [--quiet]
```
Стек агента (`python ctl.py up`) поднимает эту службу сам на порту 8000.
**Код выхода:** `2` — порт занят (служба уже поднята: окном или стеком). Живая проверка
02.10.2026: раньше на занятом порту второй экземпляр печатал «запущено» и висел молча.
Журнал службы: `D:\AI\log\copy\run_<дата>.txt` (старт, запросы, отказы).

## API (то, чем пользуются страницы)
| Метод | Точка | Что делает |
|---|---|---|
| GET | `/`, `/copy`, `/copy.html`, `/copy.css` | отдаёт страницу и её файлы из `copy_web\` |
| POST | `/api/assembly-copy-workspace-frame` | `{"action":"prepare"}` — временная папка **с меткой** + план (`файл` → `файл_copy`); `{"action":"collect"}` — копирование выбранных (`copied/occupied/missing`); `{"action":"cleanup"}` — убрать **свою** временную папку |
| POST | `/api/rename-copies-frame` | чтение/допись журнала `rename_copies.json` в рабочей папке |
| POST | `/api/save-rename-graph-frame` | записать граф переименований `rename_graph.json` |
| POST | `/api/load-rename-graph-frame` | прочитать граф |

**Формат `names` в `collect` — строка JSON** (как шлёт страница: `JSON.stringify(plan)`), не массив:
при массиве служба отвечает `ok:false` без копирования.

## Границы
- служба **не удаляет рабочие файлы**: только копирование и журналы; временные папки
  (`creo_copy_…` **с меткой `.copy_server_tmp` внутри**) сносятся своей командой `cleanup`;
  чужая папка с таким же префиксом в имени не трогается;
- по умолчанию слушает только `127.0.0.1`; при `--bind 0.0.0.0` API доступен всей сети
  **без токена** (решение хозяина службы, зафиксировано в аудите 02.10.2026);
- если порт занят, окно это покажет и предложит открыть страницу уже работающей службы.
