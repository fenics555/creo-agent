# CREO PDF — скан и обновление PDF чертежей (JLINK, без CREOSON)

Рутина дома: **рядом с чертежом `<имя>.drw[.N]` должен лежать `<имя>.pdf` той же папки и быть не старше чертежа.**
Нет PDF или PDF старее — обновить. Обход идёт по **всем подпапкам** выбранной папки.

## ОКНО (для рук)
```
creo_pdf_gui.bat            (или: python creo_pdf_gui.py)
```
| Элемент | Что делает |
|---|---|
| **Путь к config.pro** + `Обзор…` | выбрать боевой `config.pro` (обычно `Z:\PTC\CREO-START\START-STD\config.pro`) |
| **Из сессии** | показывает, откуда стартовал Creo (`cwd`) и какие `config.pro` реально найдены, плюс значения ключевых опций |
| **Применить к Creo** | применяет опции из выбранного `config.pro` к живой сессии (`SetConfigOption`) |
| **Папка проверки** + `Обзор…` | что обходить (корешки вида `Z:\PTC\Work\…`) |
| **СКАН (отчёт)** | только отчёт: где нет PDF, где PDF старше чертежа. Creo НЕ нужен |
| **лимит** | сколько PDF создавать за прогон (страховка для больших папок). **0 = без ограничения** |
| **открывать PDF** (галочка) | отмечена — каждый готовый PDF открывается в просмотрщике и остаётся открытым; снята — PDF не открываются |
| поведение Creo | каждый чертёж **показывается** (это обязательное условие PDF) и **сразу убирается из сессии** — окна в Creo не копятся |
| логи | `last_run_log.txt` рядом с программой + `logs\run_<дата>_<время>.txt` |
| перенос | всё (движок, jar, настройки `gui_settings.json`, логи) лежит в папке `creo_pdf` — переносится вместе с ней |
| **СОЗДАТЬ / ОБНОВИТЬ PDF** | создаёт недостающие/устаревшие PDF (нужен **запущенный Creo**) |
| **СТОП** | снимает процесс движка (taskkill /T /F) |
| **README** | печатает этот файл прямо в окно |
| **Где config.pro (без сессии)** | ищет `config.pro` по известным местам дома **без Creo**: какой боевой, какой без домашних путей |
| **Найти Creo (реестр)** | путь установки из реестра Windows (`HKLM\SOFTWARE\PTC\PTC Creo Parametric\<версия>\InstallDir`) |
| **Запустить Creo (штатно)** | запускает `parametric.exe` с рабочей папкой = папка выбранного `config.pro` (**без домашнего CREO-START.bat**) |
| Лог | живой поток строк + итог `чертежей: N | PDF в порядке: X | нет PDF: Y | устарели: Z` |
| **Копировать лог** | весь лог в буфер (с проверкой чтением; если Tk-буфер недоступен — резервно через PowerShell) |
| **Сохранить…** | сохранить лог в файл (UTF-8) — работает всегда, от буфера не зависит |
| **Очистить** | очистить окно лога |
| правый клик по логу | Копировать выделенное · Копировать ВЕСЬ лог · Сохранить в файл… · Показать, что в буфере · Выделить всё (Ctrl+A) · Очистить |
| автофайл лога | после каждого прогона полный лог пишется в `creo_pdf\last_run_log.txt` (ничего не теряется) |

⚠️ Буфер обмена доступен только в обычном пользовательском сеансе. Если «Копировать лог» не сработает,
лог всё равно уже лежит в `last_run_log.txt`, а кнопка «Сохранить…» пишет файл напрямую.
Выбранные пути запоминаются в `gui_settings.json`.

## ДВИЖОК (для ИИ и скриптов)
```
creo_pdf.bat scan   <папка>              # отчёт по папке и подпапкам (Creo не нужен)
creo_pdf.bat export <папка> [лимит]      # создать недостающие/устаревшие PDF; лимит 0 = без ограничения
creo_pdf.bat pdf    <папка> <имя> [out]  # один чертёж
creo_pdf.bat config-scan                 # поиск config.pro БЕЗ Creo: какой боевой, какой без домашних путей
creo_pdf.bat config-find                 # где Creo взял конфиг (cwd сессии + профиль + loadpoint)
creo_pdf.bat config-read [config.pro]    # ключевые опции: из живой сессии или из файла
creo_pdf.bat config-load <config.pro>    # применить опции дома к живой сессии
creo_pdf.bat creo-find                   # путь установки Creo из РЕЕСТРА Windows
creo_pdf.bat creo-start [config.pro] [--dry]   # ШТАТНЫЙ запуск Creo (без домашнего бата)
```
**ШТАТНЫЙ ЗАПУСК CREO (без CREO-START.bat).** Домашний бат делает ровно две вещи: `cd /d START-STD` и
`start parametric.exe` — **без ключей**. Значит штатный запуск = задать процессу `parametric.exe`
**рабочую папку с боевым `config.pro`**: Creo читает `config.pro` из рабочей папки, а оттуда приходят
форматки (`pro_format_dir`), `MY_ESKD.dtl` и `table.pnt`. Путь установки берётся из реестра Windows:
```
HKLM\SOFTWARE\PTC\PTC Creo Parametric\12.4.2.0
    InstallDir          REG_SZ  D:\PTC\CREO12\Creo 12.4.2.0\Parametric
    CommonFilesLocation REG_SZ  D:\PTC\CREO12\Creo 12.4.2.0\Common Files
```
Проверка 23.09.2026 (`creo-start … --dry`):
```
config.pro     : ЕСТЬ 17125 б  Z:\PTC\CREO-START\START-STD\config.pro
рабочая папка  : Z:\PTC\CREO-START\START-STD
parametric.exe : D:\PTC\CREO12\Creo 12.4.2.0\Parametric\bin\parametric.exe
[dry] было бы: "…\parametric.exe"  cwd=Z:\PTC\CREO-START\START-STD
```
**ЧТО ТАКОЕ «ЛИМИТ»:** это потолок числа чертежей, которые движок возьмёт в работу за один прогон
(и в отчёте `scan`, и в `export`). Нужен, чтобы прогон по огромной ветке не длился часами: поставил 50 —
обработал 50 самых «нужных» позиций и остановился. **0 = без ограничения** (идёт до конца).
Внутри (`CreoPdf.java`): `ChangeDirectory(папка)` → `ModelDescriptor_Create(MDL_DRAWING, имя)` →
**`Display()`** → `Export(<имя>.pdf, PDFExportInstructions_Create())` → возврат рабочей папки Creo.
В агенте это инструменты **`creo_pdf_scan`** (чтение) и **`creo_pdf_export`** (под щитом согласования).

## КОНФИГ И ОФОРМЛЕНИЕ (почему PDF «правильный»)
PDF берёт оформление из живой сессии, а сессия — из `config.pro`:
| Опция | Значение дома |
|---|---|
| `pro_format_dir` | `Z:\PTC\CREO-START\НАСТРОЙКИ\ФОРМАТЫ\` (163 форматки `a0…a4.frm`) |
| `drawing_setup_file` | `…\НАСТРОЙКИ\configs/MY_ESKD.dtl` — оформление чертежа (ЕСКД) |
| `format_setup_file` | `…\configs/MY_ESKD.dtl` в файле; **в живой сессии `dwgform.dtl`** |
| `pen_table_file` | `…\НАСТРОЙКА_ПРИНТЕРА/table.pnt` — перья/толщины линий |
| `pro_plot_config_dir` | `…\НАСТРОЙКА_ПРИНТЕРА\` |
| `pdf_use_pentable`, `use_8_plotter_pens` | `yes`, `yes` |
**Разница `format_setup_file` / `drawing_setup_file`:** `format_setup_file` задаёт настройки, которые
**зашиваются в форматку** (внутренний `dwgform.dtl`) — он применяется, когда форматка подгружается/создаётся;
`drawing_setup_file` применяется **к самому чертежу** (тексты, стрелки, допуски) и обновляется при работе с чертежом.
Практический вывод: если чертёж уже с домашней форматокой, PDF верен; если форматки нет — её нужно подтянуть
(`pro_format_dir` + `format_setup_file`), иначе PDF будет «пустым» по оформлению.

**Как программа узнаёт каталог Creo:** `config-find` берёт `cwd` живой сессии (там Creo и стартовал —
для дома это `Z:\PTC\CREO-START\START-STD`), профиль пользователя и loadpoint Creo, вычисленный
из `java.library.path` (`…\Common Files\x86e_win64\lib` → два уровня вверх). Первый найденный `config.pro`
и есть боевой.

## ПЕРЕНОС НА ДРУГУЮ ПАПКУ/КОМПЬЮТЕР
Портативна вся папка `creo_pdf\`: `CreoPdf.java/.class` (движок), `pfcasync.jar`, `creo_pdf.bat`,
`creo_pdf_gui.py/.bat`, настройки `gui_settings.json`, логи `last_run_log.txt` и `logs\`.
Копируешь папку — копируются и логи, и настройки. На новой машине проверь два пути в окне:
`config.pro` (папка старта Creo) и папку проверки; установка Creo ищется из реестра Windows автоматически.

## СБОРОЧНЫЕ ЧЕРТЕЖИ И УБОРКА (проверено 23.09.2026)
- **Сборочный чертёж** (`X.drw` при наличии `X.asm`) Creo не отдаёт «в голове»: `XToolkitNotFound`.
  Движок теперь **сначала поднимает сборку `X.asm`**, затем чертёж — и это работает:
  `plshaiba-4` и `plshaiba-5` (оба были «ОШИБКА») дали `PDF OK 35879 б` и `PDF OK 28592 б`, **0 ошибок**.
- **После экспорта чертёж убирается из сессии** (`Model.Erase()`), если он не был открыт инженером раньше —
  окна в Creo накапливаются только при желании. Если чертёж был в сессии ДО прогона — не трогаем.
- **Просмотрщик PDF** управляется явно: опция `PDFOPT_LAUNCH_VIEWER` = по галочке «открывать PDF»;
  без галочки ничего не открывается (и открывать PDF своими руками движок не будет).
1. `export`/`pdf`/`config-*` требуют **запущенного Creo**; `scan`/`config-find` — нет (`config-find` — да, требует).
2. Creo, запущенный из `D:\PTC\CREO-LOCAL-SETUP\CREO-LOCAL-START` (его `config.pro` 12 761 б **без** домашних путей),
   даст PDF без форматок и перьев — лечится `config-load` или стартом из `START-STD`.
3. Creo дописывает суффикс версии к экспорту (`name.pdf` → `name.pdf.1`), если файл занят.
4. Пути с пробелами/кириллицей — только в кавычках; движок терпит лишние кавычки.
5. Долгий прогон на большой папке: ставь `лимит` и дели по корешкам; окно можно остановить кнопкой СТОП.
