# _disabled — отключённые инструменты

Папка содержит инструменты, которые были отключены из работы агента.

## Содержимое
- `plm_tools.py` — инструменты PLM (отключены)
- `usage_tools.py` — инструменты учёта использования (отключены)

## Назначение
Хранение отключённого кода, который может быть восстановлен при необходимости.

## Связь с агентом
Не используется в текущей конфигурации агента.
