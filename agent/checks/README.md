# checks — проверки агента

Папка содержит инструменты проверки состояния агента и его компонентов.

## Содержимое
- `checks.py` — основной модуль проверок
- `checks_tools.py` — вспомогательные инструменты проверок
- `checks_README.md` — дополнительная документация

## Назначение
Проверка целостности данных, работоспособности инструментов, состояния баз агентов.

## Связь с агентом
Часть ядра агента — используется для мониторинга и валидации состояния системы.
