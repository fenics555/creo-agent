# АГЕНТ v12 — ИИ-напарник КБ (Creo Parametric)

Веб-агент конструкторского бюро: чат с локальной LLM (Ollama), живые данные
Creo через CREOSON, база знаний, трейлы, ГОСТ-спецификации, флот.
Только стандартная библиотека Python.

## Вход по умолчанию
`admin` / `admin` (роль Администратор). Смена: 👤 → Сменить пароль.

## Быстрый старт
1. Python 3.10+, Ollama, CREOSON 3.x, Creo 8–13.
2. `AI_START.bat` (или `python ctl.py up --browser`).
3. Открыть http://127.0.0.1:8765 (или сетевой IP:8765).

## Управление
`AI_RESTART.bat` — перезапуск без окон; `AI_STOP.bat`; `python ctl.py status`.

## Архитектура
- `agent.py` — HTTP :8765 (панель + JSON API); блоки `*_tools.py` подключаются автоматически.
- `core.py` — пути/лог/sqlite/Ollama; `settings.py` — единственный хозяин `config.json`.
- `ctl.py` — пуск/стоп/сторож стека (Ollama, CREOSON, агент).
- `kb_roots.txt` / `kb_exclude.txt` — корни и исключения индекса.
- `data/` — sqlite, config.json, бэкапы (вне git, см. `.gitignore`).

## Настройки (панель → НАСТРОЙКИ)
Группы: Главное / Разум / Поиск / Визия / Creo / Память / Сканер / Пути.
Пути (`creoson_url`, `creoson_dir`, `pdf_out`, `backup_dir`) и порядок разделов
спецификации правятся здесь, а не в коде.

## Блоки (23)
CREO (чтение), CREO-ОПЕРАЦИИ (пишущие — под щитом ✅), SPEC (ГОСТ XLSX),
FIND + USAGE (поиск и «где используется»), ЗНАНИЯ/СКАНЕР, ПАМЯТЬ/ТРЕЙЛЫ/LEARN,
1С, ПАСПОРТ, ДОСТУПЫ, ФЛОТ, ЧАТ, ВИЗИЯ, WEB, БЭКАПЫ, ДИАГНОСТИКА.

## Диагностика
`diag_run` — полная самопроверка (вердикт ПРОЙДЕН/НЕ ПРОЙДЕН);
`diag_test` — быстрый живой прогон; `creoson_full_test` — пишущий цикл на копии.
Логи: `agent_log_*.txt`, `diag_full.log`, `diag_creoson.log`.

## Git
`GIT_SYNC.bat` коммитит агент и репо; `data/` и мусор вне индекса.

## Смежный репозиторий
`creo-repo` — скиллы и справочники (Creo, Python, инженерные, производство).
