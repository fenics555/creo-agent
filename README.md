# Репозиторий кода (Agent Tools)

Этот репозиторий является ядром системы (агент-монолит).

## Состав
- **Модули инструментов**: Набор специализированных инструментов для расширения возможностей агента.
- **Витрина (Showcase)**: Интерфейс и механизмы демонстрации возможностей.
- **CTL**: Утилита управления жизненным циклом (up, down, restart).
- **Dev-утилиты**: Инструменты для разработки и тестирования.

## Быстрый старт
- ctl up / ctl down / ctl restart — управление процессами.
- ui_check — проверка целостности пользовательского интерфейса.
- GIT_SYNC.bat — синхронизация состояния с репозиторием.

## Контракты и правила
Все действия должны соответствовать правилам из D:\AI\.clinerules (см. пункты 4.7 о правилах работы и 13.9 о мини-спеках).

## Данные
Папка data находится вне git-репозитория и содержит:
- Базы данных (SQLite).
- Бекапы (data\backup\).
- Секреты и токены.
- Временные файлы (data\tmp\).

## Как добавить новый инструмент
Создайте новый модуль, который экспортирует словарь TOOLS.
